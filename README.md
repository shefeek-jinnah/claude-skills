# claude-skills

A collection of [Claude Code](https://claude.com/claude-code) skills, one folder
per skill. Each folder is self-contained: read its own `README.md` for what it
does and how to install it.

## Skills

- [`name-terminal-tab/`](./name-terminal-tab) — Names your Claude Code terminal
  tab after the project folder and current task, with a manual override.
